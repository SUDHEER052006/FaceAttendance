{{ ui.icon('privacy', 'sm') }} Privacy

A face crop is biometric data. The defaults below keep it off disk entirely; recognition is unaffected either way, because matching uses the enrolled templates, not these images. The activity feed never shows a captured face regardless of what is set here.

Store a face image with every attendance event. Off by default. Turn this on only if you need photographic proof of each punch. Stored images appear on that person's own page and nowhere else — never in the activity feed, which the kiosk shows without a login.
